我是 Perry，一位在台灣工作的軟體工程師與 QA Lead。我的日常橫跨測試策略、系統整合、Production Debugging、CI/CD、基礎設施支援與專案協調，擅長把模糊問題拆成可以追蹤、驗證、改善的系統。

我重視 Linux、Automation、Infrastructure、DevOps 與可維護的工作流程。比起只解掉一次問題，我更喜歡把問題整理成可複用的工具、文件與流程，讓團隊之後少做重複工。

長期目標是持續累積能改善工作效率與產品品質的系統能力，並把工程、QA、維運與產品思維整合成可靠的交付方法。

核心能力

Root Cause Analysis

擅長從錯誤訊息、log、資料庫狀態、API 行為與部署差異中追出真正原因，並把一次性事故整理成可重複使用的排查流程。

QA Leadership

參與需求釐清、測試設計、風險判斷、缺陷追蹤與跨部門溝通，重視讓 QA 不只是驗收，而是改善產品品質與交付節奏的系統。

Infrastructure & DevOps

熟悉 Linux、Jenkins、Docker、DNS、TLS、Zabbix、WAF 與自架服務維運，能協助處理 CI/CD、環境問題與 production incident。

Automation & Internal Tools

打造能接入 Jira、Git、測試流程與知識文件的內部工具，讓重複性工作可以被標準化、自動化，並逐步累積成團隊資產。

System Integration

處理 REST API、SOAP、資料庫、權限、網路與外部系統串接問題，習慣從架構、資料流與邊界條件一起看問題。

Product Thinking

喜歡把想法整理成產品、架構與實作計畫，重視 UX、可維護性、商業可能性，以及能否真的改善人的生活。

目前重點

QA Automation & Tooling

整理測試流程、缺陷追蹤、Jira 資訊與 Git 差異，讓 QA 工作更容易被追蹤、複用與交接。

Knowledge Systems

探索文件、搜尋、RAG、個人知識管理與長期專案脈絡保存，讓經驗能被整理、查找與延續。

Self-hosting Lab

維護 Jenkins、Nextcloud、Portainer、OpenProject、WireGuard、Ollama、Docker、Zabbix 等服務，部署於 Raspberry Pi、Oracle Cloud、Ubuntu 與 Windows 環境。

Side Products

持續探索 SaaS、automation、passive income 與 remote work 的可能性，也在打造 PHP + yt-dlp downloader 等個人產品。
